This repository contains the experimental artifacts for the paper: `Realistic Robustness Evaluation of Tabular Data Driven Models`. All evaluation results and artifacts were generated using [AURORA](https://github.com/msilva2002/AURORA).
The [configuration folder](configuration/) contains all files required to reproduce the experiments, including the [attack configuration](configuration/config\_attacks.json), [dataset configuration](configuration/config\_data.json), [CatBoost model](configuration/catboost.joblib) and [MLP model](configuration/mlp.joblib), [clean samples](configuration/clean\_samples.csv), and [target file](configuration/target.csv). While the configuration of the constrained version of the attacks differ between Catboost and MLP, for the unconstrained version, the configuration file is the same.
The adversarial examples generated by each perturbation method are available in the [adversarial examples](adversarial%20examples/) folder, and the full evaluation [report](report/) along with all associated artifacts can be found in the report folder.
